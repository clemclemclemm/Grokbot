# Grokbot

## Newsletter viewer

Open the Corematic CRM newsletter (English, six stats in a 2×3 grid) as a self-contained HTML page:

- **Path:** [`newsletter/index.html`](newsletter/index.html)
- **How to open:** click that file on this branch or in the pull request, then use GitHub’s **Raw** / preview, or download it and open it in a browser.

GitHub Pages is not enabled on this repo. If you turn it on later (Settings → Pages → deploy from `main` / `/` or `/docs`), the live URL would be `https://clemclemclemm.github.io/Grokbot/newsletter/` once the file is on the published branch.
