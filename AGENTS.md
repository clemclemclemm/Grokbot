# Grokbot agent rules

After any HTML report / newsletter change:

1. Commit and push. Open a pull request.
2. In your final message to the user, put the **GitHub Pages** links first (these open the real page on a phone):

   - Report: https://clemclemclemm.github.io/Grokbot/newsletter/
   - Site root: https://clemclemclemm.github.io/Grokbot/
   - PR: `https://github.com/clemclemclemm/Grokbot/pull/<number>`

3. Do **not** send only a `github.com/.../blob/...` or Raw URL. Those show source code, not the designed page.

4. Until Pages is live, also include this public preview (works once the repo is public):

   https://htmlpreview.github.io/?https://github.com/clemclemclemm/Grokbot/blob/main/newsletter/index.html

Keep newsletter copy, stats, and brand colours unchanged unless the user asks to change them.
